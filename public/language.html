Write programs in PrequelScript

PrequelScript uses memorable phrases in place of familiar programming constructs. The compiler translates supported programs to Python and runs them in the IDE terminal.

Operators

These phrases replace common operators. The usual symbols shown in the last column are also accepted.

Other supported expression operators

Arithmetic uses +, -, *, /, //, and %. Comparisons also include !=, >=, and <=. Use && and || for logical AND and OR; these compile to Python's and and or.

Program structure and control flow

Program

THIS IS WHERE THE FUN BEGINS
    HELLO THERE ("Hello, galaxy!");
ANOTHER HAPPY ENDING

Conditional

YOU WERE THE CHOSEN ONE (score >= 10)
    HELLO THERE ("Pass");
PERHAPS THE ARCHIVES ARE INCOMPLETE (score > 5)
    HELLO THERE ("Almost");
YOU WERE SUPPOSED TO DESTROY THE SITH
    HELLO THERE ("Try again");
ANOTHER HAPPY ENDING

Loops

I WANT MORE (JEDI i YOU ARE ON THIS COUNCIL 0; i < 3; i NOW THERE ARE TWO OF THEM)
    HELLO THERE ("%d\n", i);
ANOTHER HAPPY ENDING

THIS IS GETTING OUT OF HAND (keepGoing)
    DONT TRY IT;
ANOTHER HAPPY ENDING

UNLIMITED POWAH starts an infinite loop. Use DONT TRY IT to break and YOU UNDERESTIMATE MY POWER to continue.

Types, functions, and input/output

Type phrases are accepted for declarations and function signatures. They describe the source program; Python does not enforce C-style widths or signedness.

Function

KILL HIM (JEDI doubleIt(JEDI value))
    DO IT value * 2;
ANOTHER HAPPY ENDING

THIS IS WHERE THE FUN BEGINS
    HELLO THERE ("%d", KILL HIM NOW doubleIt(6));
ANOTHER HAPPY ENDING

Terminal input

THIS IS WHERE THE FUN BEGINS
    JEDI age;
    HELLO THERE ("Age? ");
    GENERAL KENOBI ("%d", &age);
    HELLO THERE ("Age: %d\n", age);
ANOTHER HAPPY ENDING

Run the program in the IDE, type a line in the execution terminal, and press Enter to provide input.

Arrays and comments

Arrays are represented as Python lists and support indexed access.

JEDI values[3] YOU ARE ON THIS COUNCIL {4, 8, 15};
HELLO THERE ("%d", values[1]);

A line beginning with DID YOU EVER HEAR THE TRAGEDY OF DARTH PLAGUEIS THE WISE is a comment; the rest of that line is ignored.
